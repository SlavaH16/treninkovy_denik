🐙 Záloha na GitHub

Nenastaveno

Uloží kopii tréninků a cvičení jako JSON do soukromého GitHub repozitáře. Záloha se spouští ručně tlačítkem; při každém přepsání zůstává starší verze v historii commitů.

Token se do aplikace ani localStorage neukládá. Vytvoř token jen pro vybraný soukromý repozitář s oprávněním Contents: Read and write. Nikdy ho nevkládej do kódu ani veřejného repozitáře. Použij samostatný soukromý repozitář pro zálohy.

☁️ Cloudová synchronizace

Nenastaveno

Pro synchronizaci mezi telefony je potřeba vlastní bezplatný projekt Supabase. Konfigurace se uloží jen v tomto prohlížeči; synchronizace funguje po přihlášení stejným e-mailem.

Nejsi přihlášen.

Bez konfigurace Supabase se data ukládají pouze lokálně. Nepoužívej service_role secret key v prohlížeči. Návod v README vysvětluje založení databáze a bezpečnostní pravidla.
